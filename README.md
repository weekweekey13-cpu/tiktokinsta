# TikTok / Instagram → видео Telegram-бот

Бот: [@downloader_insta_tiktokbot](https://t.me/downloader_insta_tiktokbot)

Кидаешь ссылку на TikTok или Instagram — получаешь видео в лучшем качестве без водяного знака. Перед скачиванием пользователь должен быть подписан на каналы, которые задаёт админ.

Админы: `@bonamartin69`, `@itsenlay` (`/admin`)

- добавить / убрать каналы для обязательной подписки
- кнопки «Подписаться» ведут в эти каналы
- реклама других каналов под видео и рассылка всем пользователям
- рестарт бота
